# Jason M. Munro

Personal website: [munrojm.github.io](https://munrojm.github.io/).

Static HTML, CSS, and JavaScript. No build step.

## Local preview

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open <http://localhost:8000>.

## Deployment

GitHub Pages publishes the root of `main`. Push changes to `main` to update the site.
